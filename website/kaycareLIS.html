What's included

Every feature a modern lab needs

From test request to signed-off PDF report — KayCareLIS manages the full sample lifecycle in one system.

Test Catalog

Configure your lab's test menu with department groupings, default units, and reference ranges. Catalog drives ordering, reporting, and auto-flagging automatically.

  • Departmental groupings
  • Default units & reference ranges
  • Custom ranges per patient type

Sample & Order Tracking

Every lab order gets a unique accession number (ACC-YYYY-NNNNN). Track samples from collection through processing to result sign-off with a clear status trail.

  • Unique accession numbers
  • Pending → In-progress → Resulted
  • Per-test result entry

HL7 / MLLP Instrument Integration

Connect haematology analysers, chemistry platforms, and other HL7-compatible instruments. Results transmitted from the instrument appear in KayCareLIS automatically — including instrument-generated flags.

  • HL7 v2.x ORU message parsing
  • MLLP listener on port 2575
  • Instrument flags preserved (OBX-8)

Reference Ranges & Auto-Flagging

Define numeric reference ranges per test. When a result is entered, the system automatically computes H (high), L (low), or N (normal) — no manual lookup required.

  • H / L / N computed automatically
  • Colour-coded in PDF & UI
  • Manual override supported

PDF Lab Reports

Every completed order generates a downloadable A4 PDF report with your facility header, patient demographics, results grouped by department, flags, and a signature line.

  • Facility-branded header & logo
  • Department-grouped results table
  • Colour-coded flags on print

Full Audit Trail

Every result entry, edit, and status change is timestamped and attributed to a specific user. Meets clinical and regulatory traceability requirements without any extra effort.

  • User-attributed actions
  • UTC timestamps on every event
  • Immutable log — no deletions
